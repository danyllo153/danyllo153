# Zero Hour (nome de trabalho)

Projeto independente de modernização de uma experiência de **estratégia em tempo real multiplayer online**, inspirada na essência do jogo clássico Zero Hour, com foco **competitivo** e plataformas-alvo **navegador e Windows**.

> ⚖️ **Aviso:** este é um projeto independente. Não é oficial, licenciado nem afiliado à EA ou a qualquer titular de direitos. Nenhum arquivo, código, asset ou marca do jogo original é distribuído aqui. Veja [IP_AND_LICENSES.md](IP_AND_LICENSES.md).
