### 🧪 Projeto principal: [LabFlow](https://github.com/danyllo153/labflow-whatsapp-automation)

Sistema de gestão de laboratório (mini-LIMS) que criei do zero e que **já roda localmente no laboratório**. Acabou com o preenchimento repetitivo de laudos e com o controle de prazos em planilha.

- **IA aplicada com segurança:** o analista manda texto, áudio ou foto do laudo; o Gemini (com reserva no Groq) transforma em comando, o código valida e nada é gravado sem um "sim"
- **Regras no banco:** PostgreSQL com 88 migrations versionadas, funções, gatilhos e histórico de toda alteração, as mesmas regras para o bot e o app
- **App do laboratório:** API em FastAPI (login com Argon2 e cargos) + front em React/TypeScript, com turno, leituras e laudos gerados a partir dos resultados
- **Versão Lite:** o mesmo app rodando na rede local da empresa, sem nuvem
- **BI:** painel no Power BI com 11 páginas, gerado por código e versionado no Git
- **Engenharia:** mais de 1.600 testes automáticos no GitHub Actions, 5 versões publicadas e 33 bugs reais documentados com causa raiz
- **Infra:** n8n, Docker, VPS Linux, SSH por chave, Tailscale e Evolution API self-hosted
